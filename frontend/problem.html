Before you code

How to approach the problem

Use this checklist. Do not jump straight to implementation.

1
Restate the task

Identify exactly what must be returned, what every element means, and whether the whole input must be used.

2
Find the constraint signal

Use the input constraints to decide whether O(n²), O(n log n), O(n), or another complexity is realistic.

3
Match the pattern

Ask which pattern from the lesson applies: traversal, two pointers, sliding window, hashing, binary search, prefix sums, DP, and so on.

4
Prove the invariant

Before coding, state what your pointers, window, map, or DP state means and why it remains correct after each step.

5
Test edge cases

Check empty/small input, duplicates, boundaries, already-valid input, and the largest constraint you can construct.

6
Submit your solution

After it passes, return here and use Check submission. The backend verifies your latest accepted submission (Codeforces or LeetCode) against your assigned problem and assignment time.
